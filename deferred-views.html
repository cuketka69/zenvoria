Platby (Stripe)

Klíče pro napojení na Stripe — bez nich předplatné pro pečovatelky nepůjde platit ani spravovat.

Stripe klíče

Pole nechte prázdné, pokud daný klíč nechcete měnit. Změna se projeví okamžitě, server se nemusí restartovat.

Kde klíče najít
  1. Secret Key: Stripe Dashboard → Developers → API keys.
  2. Webhook Signing Secret: Developers → Webhooks → přidejte endpoint … a zkopírujte jeho signing secret.
Postup pro spuštění ostrého provozu
  1. Ve Stripe přepněte vlevo nahoře přepínač ze Sandbox/Test na Live.
  2. V živém režimu zkopírujte Secret Key (sk_live_…) z Developers → API keys.
  3. Tamtéž v Developers → Webhooks znovu přidejte endpoint … — živý webhook je jiný záznam než testovací, i URL bude stejná.
  4. Oba klíče vložte sem a uložte — appka automaticky pozná přepnutí režimu a smaže stará testovací zákaznická ID, ať nikomu nespadne platba.

Testovací klíče (sk_test_…) neúčtují žádné skutečné peníze. Test a Live jsou ve Stripe oddělené účty — klíče, webhooky i zákazníci se mezi nimi nepřenášejí.

Nápovědný chat (AI)

Plovoucí chat na webu, který návštěvníkům a uživatelům odpovídá na dotazy o ZENVORIA pomocí OpenAI.

OpenAI klíč

Pole nechte prázdné, pokud klíč nechcete měnit. Změna se projeví okamžitě, server se nemusí restartovat.

Kde klíč najít

platform.openai.com → API keys → Create new secret key. Klíč se zobrazí jen jednou, hned si ho zkopírujte.

Chat je dostupný i nepřihlášeným návštěvníkům a je omezený na 20 zpráv / 15 minut na osobu, ať nedojde ke zneužití — každý dotaz totiž stojí reálné peníze u OpenAI.
